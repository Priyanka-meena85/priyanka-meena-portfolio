INTERACTIVE & ENGAGEMENT FEATURES ADDED
---------------------------------------
0. Dual Theme Mode (Light / Dark & System Configuration Auto-Detection):
   - Header toggle button (Sun/Moon animated icons) for 1-click theme switching.
   - Automatically adapts to the visitor's OS configuration (`prefers-color-scheme: dark/light`).
   - Remembers preference across browser reloads via `localStorage`.
   - Includes full dark mode palette (Midnight Obsidian Plum #0f0c15).
1. Reading & Scroll Progress Bar:
   - Dynamic 3.5px gradient line at the top of the viewport indicating scroll depth.
2. Active Navbar Scrollspy:
   - Automatically detects current section in view and highlights the active nav link pill.
3. Ambient Particle Canvas:
   - Floating interactive particle mesh in the Hero background reacting to view geometry.
4. Mouse-Tracking Spotlight Glow:
   - Radial illumination follows mouse movement across project, stat, experience, and contact cards.
5. Animated Number Counters (CountUp):
   - Stat figures (3+ SaaS Platforms, 85+ Lighthouse CWV, 3 Enterprise Orgs, 40% Traffic Gain) smoothly count up when scrolled into view.
6. Interactive Project Category Filtering:
   - Filter buttons (All, Full-Stack SaaS, AI & Automation, Web & Assessment) with smooth animated card transitions.
7. Interactive Tech Stack Highlighting:
   - Clicking any technology badge (Next.js, React, Node.js, Python, MongoDB, etc.) smoothly scrolls to matching projects and highlights them with a temporary glowing ring.
8. Project Quick-View & Architecture Modal:
   - "System Architecture & Specs" button on every project card opens a modal detailing system architecture, Lighthouse benchmarks, Core Web Vitals (LCP, CLS), and direct links.
9. Interactive Direct Contact Message Composer:
   - Modal contact form allows visitors to compose inquiries with 1-click email client dispatch and draft clipboard copying.
10. Quick "Copy to Clipboard" with Floating Toast Notifications:
    - 1-click email and phone copying with an animated bottom-right toast confirmation.
11. Floating Back-to-Top Button with Circular Scroll Progress:
    - Circular SVG progress ring that fills as the page is scrolled and smoothly returns to top on click.
12. Interactive Animated Skill Bars:
    - Progress bars smoothly animate to their target percentages via IntersectionObserver.
13. Dedicated Resume View:
    - Exact reproduction of the reference site's /resume page with working embedded PDF preview and high-fidelity download.
14. Embedded Real Production Screenshots:
    - KaamMitra, The Optical Hub, CareWell Clinic, RentMitraa, and ForgeFlow cards feature real web app screenshots embedded as base64 with smooth zoom hover and modal preview.
15. Recommendations:
    - Feature recommendation from Karan Singh Rathore, Software Developer @ JRS Innovation, with quotation badge, date, and LinkedIn profile link.

HOW TO USE
----------
1. Open index.html directly in any browser to preview.
2. To host for free, upload index.html to:
   - GitHub Pages — push to a repository and enable Pages in Settings
   - Vercel (vercel.com) — drag & drop deploy
   - Netlify (netlify.com) — drag & drop deploy
